# LightController — LED Light Show Engine

**Role in Kwal27:** Renders all light shows on the 160-LED FastLED strip arranged in 6 concentric rings. Supports two rendering paths: the default `CircleShow` (distance/angle-based per-pixel blend) and `RingShow` (6-ring gradient scrolling + lerp targets for TV simulator). Brightness is controlled via a calibrated lux-driven curve with web UI override.

## Files

### LightController.h / LightController.cpp
Top-level LED control interface. Defines:
- `LightShowParams` — struct holding all CSV-column parameters for a single light show: `RGB1`/`RGB2` base colors, fade width (`fadeWidth`), gradient speed (`gradientSpeed`), center/animation offsets (`centerX`, `centerY`, `radius`, `radiusOsc`, `xAmp`, `yAmp`), cycle speeds (`colorCycleSec`, `brightCycleSec`, `xCycleSec`, `yCycleSec`), `patternType` string (empty = CircleShow, `"RingGradient"` = 6-ring), and radial pattern fields (`angleWeight`, `petalCount`).
- `GRADIENT_SIZE` = 256 — fixed color gradient LUT
- `leds[]` — the 160-element `CRGB` FastLED array
- Public API: `PlayLightShow(params)` (one frame), `updateLightController()` (periodic tick), `MakeSolidParams(color)` (solid-color shortcut), brightness getters/setters (`getWebMultiplier`, `setWebMultiplier`, `getSliderPct`, `getBrightnessShiftedHi`, etc.)

`LightController` class itself is a pure-static singleton (no instance members); global handle `extern LightController lightController`.

`LightController.cpp` contains the main `playLightShow()` implementation which:
1. Computes animated center position from `centerX`/`centerY` + oscillation
2. Builds the 256-entry gradient LUT from `RGB1` → `RGB2`
3. Calls `CircleShow()` (default) or `updateRingShow()` (pattern_type patterns) per frame
4. Applies brightness scaling via the lux calibration curve and web multiplier

### LEDMap.h / LEDMap.cpp
Maps LED indices (0–159) to physical positions in polar coordinates (angle, distance from center). Used by `CircleShow` to compute per-LED color based on distance from the animated center point. LED positions are generated by the `generate_ledmap.py` tool and verified by `verify_ledmap.py`.

### LightManager.cpp (no .h)
Brightness manager. Computes the final LED brightness from three inputs: base brightness from the ambient light (lux) sensor calibration curve, web UI slider override, and any active shift/override (calendar, TV mode). Implements `getEffectiveBrightness()` consumed by `LightController.cpp`.

### RingShow.h / RingShow.cpp
Unified 6-ring renderer with two distinct inputs:

**Lerp Targets** (`setRingTargets()` + `renderRings()`): Used by the TV simulator and demo RingScene. Each of the 6 rings has a target color+brightness. The renderer smoothly fades current ring colors toward targets (or hard-cuts if `instant = true`), then writes to `leds[]` and calls `FastLED.show()`.

**Gradient Scrolling** (`updateRingShow()`): Used by `patternType = "RingGradient"` patterns. Scrolls a 256-color gradient across the 6 rings with configurable `gradientSpeed` and `colorPhase`. Each ring gets a horizontal slice of the gradient, producing a "rainbow wheel" scrolling effect.

Ring LED layout (defined in `RingShow.cpp`):
- `ringStart[]` = `{ 0, 8, 24, 48, 80, 116, 160 }` — 6 rings with 8, 16, 24, 32, 36, 44 LEDs each.

Also contains the default `CircleShow()` renderer: blends `RGB1`/`RGB2` per LED based on its distance from an animated center point, with optional angular weighting via `angleWeight`/`petalCount` for radial/petal patterns.
