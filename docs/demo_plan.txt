DEMO MODE — PLAN
=================
Status: discussie/ontwerp. Nog geen code.
Datum: 2026-06-02

DOEL
----
WebGUI-knop "Demo" start een demonstratiemodus voor een instelbare duur
(gele slider). Demo toont aan publiek (binnen ~2 m) wat Kwal kan, zowel
qua rustige Kwal-natuur als qua uitbundige/feestelijke effecten.
Publiek: algemeen publiek, geen technici. Nederlandse TTS-narratie
structureert de show.


HARDE PRINCIPES
---------------
1. ZO WEINIG MOGELIJK NIEUWE INFRASTRUCTUUR.
   - Geen nieuwe render-engine (geen DemoShow.cpp).
   - Geen nieuwe audio-engine, geen beat-detectie bouwen (beat feedback
     bestaat al).
   - Geen nieuwe submap per categorie.

2. ALLES VIA BESTAANDE MECHANISMEN.
   - Patterns: nieuwe rijen in light_patterns.csv (demo-IDs).
   - Colors:  nieuwe rijen in light_colors.csv (demo-IDs).
   - Audio:   /150/NNN.mp3 (één submap voor alles: TTS + muziek + geluid).
   - Render:  bestaande PlayLightShow engine, geen render-switch.
   - Timing:  bestaande TimerManager.
   - Audio play/stop: bestaande PlayAudioFragment + durationMs/fadeMs.

3. DEMO = ORKESTRATIE, niet rendering.
   - cb_demoNextChapter() in lib/RunManager/ schakelt chapters.
   - Per chapter: requestPatternId() + requestColorsId() + audio.
   - Eén flag (demoActive) onderdrukt normale kalender/context switches
     tijdens de demo — analoog aan tvMode, maar op orchestratie-niveau.


STRUCTUUR PER CHAPTER
---------------------
Elk chapter heeft twee fasen, sequentieel:

  Fase A — Aankondiging (TTS)
    - Audio:   /150/NNN.mp3 (TTS-tekst; jij maakt de MP3's)
    - Duur:    = lengte van de TTS-MP3
    - Visueel: hetzelfde effect als fase B van dit chapter

  Fase B — Show (effect)
    - Visueel: bestaand pattern + colors via demo-rijen in de CSV's
    - Audio:   uit /150/ (muziek/geluid)
    - Duur:    configureerbaar

Alle audio loopt/stopt via timers + AudioFragment.durationMs (standaard).


AUDIO-OPZET
-----------
Een submap: /150/   (demo)
  - Bevat TTS, muziek en geluidseffecten door elkaar.
  - Index vrij toe te wijzen per chapter.
  - Jij genereert alle MP3's zelf (geen PowerShell, geen API-script).

Apart: /149/        (TTS-cache, voor vrije-tekst WebGUI + kalender)
  - ttsCacheDirIndex wordt verplaatst van 127 → 149.
  - Reden: /127/ wordt gebruikt door theme boxes BIRDS / ALLBIRDS /
    BIRDS8 (zie theme_boxes.csv). Conflict tussen TTS-cache writes en
    vogelgeluid-fragments.
  - Wijziging: Globals::ttsCacheDirIndex default 127 → 149 in Globals.h.
  - /127/ blijft beschikbaar voor de bestaande BIRDS-fragments.

SLIDER
------
- Gele slider in WebGUI bepaalt totale demo-duur.
- Voorlopig bereik: 30 – 180 sec, default ~90 sec.
- Korte duur = alleen highlights; lange duur = alles + langere chapters.
- Implementatie: chapter-tabel geeft min-duur per chapter; demo schaalt
  of selecteert chapters op basis van slider — exacte regel nog te
  bepalen.
