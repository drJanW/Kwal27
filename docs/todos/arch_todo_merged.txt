4) AUDITED 2026-03-12 — Controller status accessor inventory.
   Rule: controllers touch hardware and set status; reads come from AlertState/memory.

   CLEAN (no violations):
   - AudioManager: isPCMClipActive() returns cached internal state ✓
   - SensorController: distanceMillimeters(), ambientLux() return cached atomics ✓
   - LightController: getWebMultiplier(), getSliderPct(), getBrightnessShiftedHi() all cached ✓
   - ContextController: isTimeSynced() returns cached flag ✓
   - CalendarSelector: hasCalendarData(), isReady() return cached flags ✓
   - TimeOfDay: isNight(), isDawn() etc. compute from cached PRTClock ✓
   - WebInterfaceController, WiFiController: no public status-read methods ✓

   VIOLATIONS (low-risk but architecturally wrong):
   a) RTCController::getTemperature() — I2C hardware read every call.
      Fix: cache in memory, read via timer callback once/minute.
   b) RTCController::wasPowerLost() — I2C hardware read every call.
      Fix: read once at boot, cache forever (flag never changes per session).
   c) SDController::checkPresent() — SPI probe (SD.totalBytes()) every call.
      Fix: move probe to timer callback, callers use AlertState::isSdOk().

5) WiFiController has timer callbacks that belong in a WiFiRun layer.
   - cb_checkWiFiStatus, cb_checkWiFiConnection, cb_retryConnect own timers + AlertState transitions.
   - WiFiController should be hardware API only: connect(), disconnect(), isConnected(), getIP().
   - Timer orchestration, retry logic, and the consecutive-failure counter move to WiFiRun.
   - Files: lib/WiFiController/WiFiController.cpp → split into lib/RunManager/WiFi/WiFiRun.cpp
   - Risk: touches WiFi boot sequence; USB-only recovery if broken. Do on a calm day.

6) Rename AlertState → naam dekt de lading niet meer.
   - AlertState is gegroeid tot gedeelde hardware-status + operationele vlaggen (sdBusy, syncMode) + policy gating (canPlayFragment, canFetch, etc.).
   - De naam "Alert" is misleidend — het is geen alert-systeem, het is system-breed status + gating.
   - Kandidaten: SystemStatus, HardwareGate, SystemGate — nog te beslissen.
   - Scope: namespace rename in 20+ bestanden, AlertState.h/cpp → nieuwe naam.
   - Bestanden: lib/RunManager/Alert/AlertState.h, AlertState.cpp, alle call sites.
